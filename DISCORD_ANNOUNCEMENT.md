# PartyGames Bot Is Here

We added **PartyGames Bot**, a slash-command party games bot with buttons, profiles, leaderboards, and Vibe Coins.

## Start Here

```text
/help
/setup
/daily
```

## Popular Games

```text
/tod start
/tictactoe opponent:@friend
/connect4 opponent:@friend
/rps opponent:@friend
/hangman
/battleship opponent:@friend
/wordchain starting_word:party
/trivia
```

## Truth Or Dare

Use:

```text
/tod start
```

Then press:

- Join
- Spin Bottle
- Truth
- Dare
- Custom Truth
- Custom Dare

The bottle chooses the player. Custom prompts must stay safe and age-appropriate.

## Progression

```text
/daily
/profile
/leaderboard
/shop
/buy
```

Win games and claim daily rewards to earn **Vibe Coins**.

## Safety

Use:

```text
/report
```

The bot has filtering, cooldowns, and report tools. Keep games friendly and server-safe.
